This addon adds an optional workspace interface for OCA DMS.

It provides a more familiar file and folder workspace with a folder
tree, content cards/list view, inspector pane, context menus, upload
actions, archive and restore flows, and responsive layout behavior.

The addon keeps the existing DMS models, storage, permissions, content
routes, and technical file/directory views available.

Configuration
=============

No configuration is required for normal use.

The DMS settings include navigation options to show or hide the original
DMS Files and Directories menu entries. They also include an option to
bypass the delete confirmation dialog for installations that prefer
faster delete/archive workflows.

Usage
=====

1. Install the addon.
2. Open *Documents > Documents*.
3. Use the folder tree to navigate directories.
4. Select files or folders in the workspace to inspect details and open
   the context menu.

DMS managers can still access the original DMS Files and Directories
pages when those menu entries are enabled in the DMS settings.
