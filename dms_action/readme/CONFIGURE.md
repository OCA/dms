1. Create a server action for the **DMS File** (`dms.file`) model.
2. Go to **DMS > Configuration > Actions** and create a DMS action.
3. Enter a name, select **Server Action** as the kind and choose the server
   action to execute. Optionally, set a Font Awesome icon, such as `fa-play`.
4. Select the **Directories** where the action should be available. Actions
   apply to files directly in those directories; subdirectories do not inherit
   them automatically.
5. Optionally, select **Allowed Groups**. Users must belong to at least one of
   the selected groups to see and execute the action. Leave this field empty
   to allow all DMS users who have access to the file and action.

Archive a DMS action to hide it from the menus and prevent its execution.
