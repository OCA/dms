Open a file in one of the configured directories.

- In the form view, open the standard action menu (gear icon) and select an
  action from the **DMS Actions** section.
- In the kanban view, open the card menu and select an action from the
  **DMS Actions** section.

The selected server action runs on that file. The view refreshes afterwards
to reflect changes. The DMS section is only displayed when actions are
available for the current file and user.
