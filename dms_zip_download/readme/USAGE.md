## Downloading Files as ZIP

To download multiple DMS files as a ZIP archive:

1. Navigate to Documents > Files
2. Open any directory containing files
3. Select multiple files using the checkboxes in list view
4. Click on the Action menu (⚙️)
5. Select "Download as ZIP"
6. The browser will download a ZIP file containing all selected files

## Configuration

To configure the maximum size limit for ZIP downloads:

1. Go to Settings > Documents
2. Find the "ZIP Download Limit" field in the File Upload section
3. Enter the maximum size in MB (set to 0 for no limit)
4. Save the settings

The default limit is 100 MB. If users try to download files that exceed this limit, they will receive an error message showing the total size of selected files.

## Notes

- Files maintain their original names and extensions in the ZIP
- If multiple files have the same name, they will be automatically renamed (e.g., file.txt, file_1.txt, file_2.txt)
- The ZIP file is compressed using standard ZIP deflation for smaller download sizes
